說明 AI Usage Dashboard 與 Win-CodexBar 的功能差異與選用建議

01

選用建議

想在同一浮窗並列查看 Claude／Codex／Copilot／Grok 多個帳號的用量選 AI Usage Dashboard

更多服務；部分來源的歷史、花費、通知，或腳本整合選 Win-CodexBar

02

功能差異比較

功能AI Usage DashboardWin-CodexBar
多帳號檢視
  • Claude／Codex／Copilot／Grok：多帳號在浮窗並列、逐卡更新。
  • Antigravity：目前只顯示一張卡。
  • Codex 多帳號可一起更新額度。
  • 個別額度在設定頁；系統匣主畫面不並列。
  • Claude 帳號可儲存與切換。
  • Claude 多帳號同頁總覽需外部工具 claude-swap。
支援範圍
  • 支援 Claude、Codex、Copilot、Grok、Antigravity 五種服務。
  • 服務範圍較廣。
  • 各來源提供的功能不同。
歷史與通知
  • 以目前額度為主。
  • 公開版未見歷史趨勢圖。
  • 公開版未見額度門檻的系統通知。
  • 部分來源有歷史、花費分析與通知。
  • Codex 個別帳號額度目前不會逐帳號觸發通知。
登入與整合
  • 需安裝對應的官方工具。
  • Claude／Codex 各卡分開保存登入設定。
  • 不匯入瀏覽器 cookie。
  • 登入方式依服務而異。
  • 可接腳本流程。

試用前先核對服務、帳號方案與登入方式；Win 的多帳號畫面與逐帳號通知請實際確認。
