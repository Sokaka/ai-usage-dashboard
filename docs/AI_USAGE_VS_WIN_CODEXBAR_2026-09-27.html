這份簡報整理 AI Usage Dashboard 與 Win-CodexBar 的優缺點，協助團隊依需求選用。

截至 2026-09-27 最新正式版：AI Usage Dashboard v1.0.13／Win-CodexBar v0.60.3

要在同一浮窗並列看多個支援帳號，先試 AI Usage Dashboard；要更多服務，或部分來源的歷史／花費、通知與流程整合，先試 Win-CodexBar。

各自的優缺點

AI Usage Dashboard

優點

  • Claude／Codex／Copilot／Grok 的多個帳號可在同一浮窗並列，逐卡刷新。
  • Claude／Codex 各卡分開保存登入設定；不匯入瀏覽器登入資料（cookie）。

限制

  • 支援五種服務；Antigravity 目前只能顯示一張帳號卡。
  • 主要顯示每張卡目前的額度。公開版未見歷史趨勢圖或額度門檻的系統通知；使用前需安裝對應服務的官方工具。

Win-CodexBar

優點

  • 服務範圍較廣；部分來源有歷史、花費分析與通知。
  • 能接到腳本流程；加入 Win 的多個 Codex 帳號可一起更新額度。

限制

  • 系統匣主畫面不並列各帳號；Codex 各帳號額度要到設定頁看。
  • Claude 帳號可儲存與切換。若要同頁看多個帳號的額度，需另接外部工具 claude-swap。
  • 登入方式、歷史與通知支援依服務而異；設定頁中各個 Codex 帳號的額度，目前不會逐帳號觸發通知。

選用建議

  1. 選 AI Usage Dashboard：主要看 Claude／Codex／Copilot／Grok，想在工作時一眼比較多個帳號。
  2. 選 Win-CodexBar：需要更多服務、部分來源的歷史／花費或通知，或想接到腳本流程。

先核對服務、帳號方案與登入方式，再用團隊帳號試用；特別確認 Win 的多帳號畫面與逐帳號通知。

依正式版 Release、文件與程式碼查核；尚未用兩款工具的真人帳號逐項試用。
