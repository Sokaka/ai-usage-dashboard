# CLI 相容性

本文件列出 AI Usage `1.0.0` 候選版的 CLI 版本要求及實測狀態。一般安裝與帳號設定請見[使用說明](../使用說明.md)。

## 版本要求

版本符合要求後，仍須通過官方來源、簽章與通訊檢查。**排錯基準只供比較，不是唯一支援版本，也不是實測通過的證明。**

| 平台 | 可嘗試的版本 | 排錯基準／隨附版本 |
| --- | --- | --- |
| Claude | 可辨識的三段式正式版，`>=2.1.169` | 基準 `2.1.169` |
| Codex | 可辨識為官方 `codex-cli x.y.z` 的正式版，排除 `0.0.0` | 基準 `0.144.1` |
| GitHub Copilot | 使用 App 隨附的 CLI，無須另行安裝 | CLI `1.0.79`／SDK `1.0.11` |
| Grok | 通過官方來源檢查後，依實際通訊判斷；版號不同或無法解析不會單獨阻擋 | 基準 `1.0.3` |
| Antigravity | 三段式正式版，`>=1.1.11` 且 `<2.0.0` | 基準 `1.1.11` |

- **預覽版**：Claude、Codex 與 Antigravity 不接受預覽或非標準版號。Grok 的來源、執行與通訊檢查仍須通過。
- **既有 Antigravity 連接**：`1.1.7`／`1.1.9` 僅保留已審查的舊流程；新增或重新連接前，請依[使用說明](../使用說明.md#支援平台)更新。
- **更新影響**：CLI、登入流程、用量格式或官方簽章變更都可能影響相容性。版本範圍不表示未來版本已完成測試。

## CLI 更新後遇到問題

- **讀取仍正常**：可以繼續使用；未列在實測表不代表不支援。
- **來源或版本檢查失敗**：依畫面提示確認官方工具與版本，保留錯誤訊息；請勿繞過安全檢查。
- **讀取失敗**：記下 App／CLI 版本及錯誤，確認是否有對應的 App 相容性修正。依畫面提示處理，不要只因版號不同就降版。
- **明確要求重新連接**：重新連接該張卡片；登入失效或網路問題不應直接判定為版本衝突。

維護者的檢查頻率、實測範圍與紀錄方式見[CLI 相容性維護](../INTERNAL_DISTRIBUTION.md#cli-相容性維護)。
