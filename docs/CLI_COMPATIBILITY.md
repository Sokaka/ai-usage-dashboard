# CLI 相容性

本文件列出 AI Usage `1.0.5` 正式版本的 CLI 版本要求及實測狀態，並保留歷史版本紀錄。本版本的 Copilot 使用本機官方 CLI，主包不隨附第三方 CLI。`1.0.5` 的五個平台尚未完成真人登入與完整用量驗收；舊版 Claude／Copilot 的受控查證只列在對應歷史表。一般安裝與帳號設定請見[使用說明](../使用說明.md)。

## 版本要求

版本符合要求後，仍須通過官方來源、簽章與通訊檢查。**排錯基準只供比較，不是唯一支援版本，也不是實測通過的證明。**

| 平台 | 可嘗試的版本 | 排錯基準／SDK 版本 |
| --- | --- | --- |
| Claude | 可辨識的三段式正式版，`>=2.1.169` | 基準 `2.1.169` |
| Codex | 可辨識為官方 `codex-cli x.y.z` 的正式版，排除 `0.0.0` | 基準 `0.144.1` |
| GitHub Copilot | 本機官方 CLI 的三段式正式版，`>=1.0.79` 且 `<2.0.0` | CLI 基準 `1.0.79`／App 固定 SDK `1.0.11` |
| Grok | 通過官方來源檢查後，依實際通訊判斷；版號不同或無法解析不會單獨阻擋 | 基準 `1.0.3` |
| Antigravity | 三段式正式版，`>=1.1.11` 且 `<2.0.0` | 基準 `1.1.11` |

- **Copilot**：`1.0.79` 是 SDK `1.0.11` 的既有配對與起始支援基準；其他 `1.x` 未宣稱實測通過，仍須通過實際 RPC 與帳號驗證。來源限目前 Windows 使用者的 WinGet 標準套件、標準 npm 安裝或 `PATH` 可解析的真正官方 `copilot.exe`；不執行 `.cmd`／`.ps1` wrapper，也不退回舊 App 隨附的 CLI。來源檢查與受保護副本見[技術總覽](TECHNICAL_OVERVIEW.md#github-copilot-串接)。
- **預覽版**：Claude、Codex、Copilot 與 Antigravity 不接受預覽或非標準版號。Grok 的來源、執行與通訊檢查仍須通過。
- **既有 Antigravity 連接**：`1.1.7`／`1.1.9` 僅保留已審查的舊流程；新增或重新連接前，請依[使用說明](../使用說明.md#支援平台)更新。
- **更新影響**：CLI、登入流程、用量格式或官方簽章變更都可能影響相容性。版本範圍不表示未來版本已完成測試。

## CLI 更新後遇到問題

- **讀取仍正常**：可以繼續使用；未列在實測表不代表不支援。
- **來源或版本檢查失敗**：依畫面提示確認官方工具與版本，保留錯誤訊息；請勿繞過安全檢查。
- **讀取失敗**：記下 App／CLI 版本及錯誤，確認是否有對應的 App 相容性修正。依畫面提示處理，不要只因版號不同就降版。
- **明確要求重新連接**：重新連接該張卡片；登入失效或網路問題不應直接判定為版本衝突。

維護者的檢查頻率、實測範圍與紀錄方式見[CLI 相容性維護](../INTERNAL_DISTRIBUTION.md#cli-相容性維護)。
