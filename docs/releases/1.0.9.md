`1.0.9 / sequence 1023` 已正式公開。從 [v1.0.9 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.9) 下載；一般安裝與帳號設定見[使用說明](../../使用說明.md)。

## 本版內容

- 本版 App 沿用 `1.0.8` 的功能，包括 Codex 可用重置券的最近到期時間、到期前 48 小時警示色與逐券資訊視窗。舊版 CLI 只回傳可用次數時仍顯示次數，不推測逐券資料或到期時間。
- 發版流程可在 App 升版時沿用前一正式版已簽署的 Updater。本版沿用 `1.0.8` Updater 的原始 bytes，維護 Updater 的版號維持 `1.0.8`。
- 修正歷史版本說明與隨包使用指南指向目前版本的連結。

## 尚未完成的驗收

本版尚未以五個平台的實際官方 CLI 完成真人登入與用量查詢，也未逐版實測舊版與最新版 CLI。先前版本的真人結果及本版的合成回歸測試都不代替本版實測；逐平台狀態見 [CLI 相容性表](../CLI_COMPATIBILITY.md#109)。

`1.0.8` 已安裝 App 的 **更新並重新啟動** 按鈕至本版、實際安裝與 Windows 安裝紀錄核對仍待驗證。匿名下載與簽章 smoke 不能證明先前的 `update release feed is not valid JSON` 問題已在 App 端到端更新中解決；舊版 Updater 自我交接、乾淨 Windows 初裝及完整 UI／無障礙驗收也尚未完成。

服務串接依賴各平台官方 CLI 或 SDK；上游變更可能影響讀取。自有 EXE 尚無 Authenticode 簽章，Windows reputation 或端點政策可能提示或阻擋；請保留安全防護。已公開的版本不可替換成品，修正須使用新版本與遞增 sequence。
