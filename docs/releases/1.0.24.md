# AI Usage Dashboard 1.0.24

`1.0.24 / sequence 1038` 已沿用同一組凍結候選正式公開。[v1.0.24 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.24) 為 stable／latest；App 為 `1.0.24`，Updater 沿用 `1.0.23`。

## 本版內容

- Claude 原始方案為 Max，且這張卡片的本機倍率明確為 20x 時，標題顯示 `ultra`；5x 顯示 `max`。
- 倍率缺失、未知、無法讀取或資料不一致時保留 `max`。方案名稱不依用量百分比或 5 小時列是否存在推測。
- 倍率只作顯示補充，不變更原始訂閱分類、帳號／組織綁定或用量安全檢查；不增加 CLI 或 API 查詢。

## 升級

帳號、偏好與既有連接保留，快取格式與 CLI 版本要求維持，不需清除設定或重新登入。舊快取的 `max` 會在該卡片下一次成功查詢、且取得明確倍率後更新顯示；已保存的 CLI metadata 並非獨立的即時訂閱驗證。

App 為 `1.0.24`；候選流程已核對並沿用前一正式版 `1.0.23` 的同一組 Updater bytes、版本與 source。SDK 固定 `8.0.427`，內附 runtime `8.0.33`，第三方元件與授權 manifest 不變。
