# AI Usage Dashboard 1.0.24

`1.0.24` 正在準備候選；尚未公開，目前正式版仍為 [v1.0.23](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.23)。

## 本版內容

- Claude 原始方案為 Max，且這張卡片的本機倍率明確為 20x 時，標題顯示 `ultra`；5x 顯示 `max`。
- 倍率缺失、未知、無法讀取或資料不一致時保留 `max`。方案名稱不依用量百分比或 5 小時列是否存在推測。
- 倍率只作顯示補充，不變更原始訂閱分類、帳號／組織綁定或用量安全檢查；不增加 CLI 或 API 查詢。

## 升級

帳號、偏好與既有連接保留，快取格式與 CLI 版本要求維持，不需清除設定或重新登入。舊快取的 `max` 會在該卡片下一次成功查詢、且取得明確倍率後更新顯示；已保存的 CLI metadata 並非獨立的即時訂閱驗證。

App 為 `1.0.24`，預計沿用前一正式版 `1.0.23` 的同一組 Updater bytes，須由候選流程核對。SDK 固定 `8.0.427`，內附 runtime `8.0.33`，第三方元件與授權 manifest 不變。
