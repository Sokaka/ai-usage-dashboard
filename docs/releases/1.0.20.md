# AI Usage Dashboard 1.0.20

`1.0.20 / sequence 1034` 已沿用同一組凍結候選正式公開。[v1.0.20 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.20) 為 stable／latest；下載資訊見 [README](../../README.md#current-release)。App 為 `1.0.20`，Updater 沿用前一正式版交付的 `1.0.18` 原始 bytes。

## 本版內容

- Claude Code `2.1.292` 的 `/usage` 回應若缺少 root `safety_stops`，或該欄位精確為零，會繼續解析額度；非零 safety stop 仍停止自動查詢，其他未知安全欄位仍拒絕採用。
- 保留 `fallback_credit: null` 及舊回應格式；Claude Code 最低版本仍為 `2.1.169`。沒有額度數字的回應不會被當作有效額度。
- Claude、Codex、Grok 優先執行已驗證且鎖定的官方原始 EXE。Claude 來源 ACL 不符時，使用已核對 SHA-256、ACL 與簽章的受保護副本；Copilot 保留既有副本路徑。
- 程序在建立時直接加入 Windows Job Object，保留結束確認、quarantine 與帳號隔離。Grok operation deadline 可注入計時，逾時回歸由測試明確觸發；正式入口仍使用系統計時與原有期限。

## 升級

帳號、偏好、用量與 provider 綁定檔案格式維持原有契約；既有卡片不會只因 App 更新而要求重新連接。官方來源、簽章、程序與帳號隔離要求維持，CLI 版本範圍見 [CLI 相容性](../CLI_COMPATIBILITY.md)。Updater 沿用前一正式版的相同 bytes；第一次透過舊 `1.0.16` Updater 升級的中文完成提示限制仍見 [1.0.18 升級說明](1.0.18.md#升級)。
