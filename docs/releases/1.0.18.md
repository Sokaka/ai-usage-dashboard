# AI Usage Dashboard 1.0.18

`1.0.18 / sequence 1032` 待建立候選，尚未正式公開。App 與新版 Updater 將由同一 source 建置，不沿用 `1.0.16` Updater；目前下載請見 [README](../../README.md#current-release)。

## 本版內容

- 更新程式的完成、重新啟動及已是最新版提示提供 English／繁體中文，沿用 App 選擇的語系。
- 從 App 啟動更新時傳遞目前語系；直接執行新版 Updater 時讀取已保存的語系，沒有設定時使用 English。
- 已知的更新結果及附加警告使用同一語系，原始錯誤、路徑與版本資訊保留。

本版保留 [1.0.17](1.0.17.md) 的卡片警示翻譯修正，以及先前的語系切換、設定匯入匯出與效能調整。

## 升級

帳號、有效連接與設定格式沿用 `1.0.17`；本機 preferences schema `8`、匯出設定 schema `7` 不變。更新程式只讀取語系，不改寫帳號或設定。

**第一次由舊 Updater 升級時，最後的完成提示仍可能是中文。** `1.0.16` Updater 會在交接新版後自行顯示舊文案，新版無法改變已在執行的舊程式。新版維護 Updater 接手後，由它顯示的更新提示會使用所選語系。直接使用本版 Updater 則不經過舊程式的完成提示。
