## 本版內容

- Grok CLI 提供的方案通過驗證、且對應目前卡片帳號時，卡片標題會顯示方案；資料缺少或無法確認時不猜測。
- 修正 GitHub Copilot 卡片的方案顯示：僅顯示與目前帳號相符且可確認的方案，並將 `individual_pro` 等回傳值轉為 `Pro+` 等可讀名稱。用量暫時無法取得時，已確認的方案仍可顯示。
- AGY 的子程序等待回歸測試改用明確訊號，驗證根程序結束後仍會等待子程序；這項調整不改變 App 的執行路徑。
- 本版沿用前一正式版已簽署的 `1.0.8` Updater 原始 bytes，維護 Updater 版本仍為 `1.0.8`。

## 尚未完成的驗收

本版尚未以五個平台的實際官方 CLI 完成真人登入與用量查詢，也未逐版實測舊版與最新版 CLI。從既有 `1.0.9` 標準安裝執行 App 按鈕的 signed online update、乾淨 Windows 初裝、舊版 Updater 自我交接及完整 UI／無障礙驗收亦未以本版完成；先前版本的真人或安裝結果及本版合成回歸測試都不代替本版實測。逐平台狀態見 [1.0.10 CLI 相容性表](../CLI_COMPATIBILITY.md#1010)。

服務串接依賴各平台官方 CLI 或 SDK；上游變更可能影響讀取。自有 EXE 尚無 Authenticode 簽章，Windows reputation 或端點政策可能提示或阻擋；請保留安全防護。已公開的成品不可替換，修正 bytes 須使用新版本與遞增 sequence。
