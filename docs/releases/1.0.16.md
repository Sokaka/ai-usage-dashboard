## 本版內容

- App 預設使用 English。從浮窗 **⋯ → Language** 或系統匣的 **Language** 子選單，可立即切換 **English**／**繁體中文**；中文介面使用 **語系** 子選單。
- 語系包含在設定匯出、匯入及還原匯入前設定中。舊匯出檔沒有語系時，保留目前選擇。
- 英文介面涵蓋視窗、卡片、連接、匯入、用量與更新提示。使用者暱稱及未知來源的原始診斷保留原文。
- Repository README 預設使用英文，繁中說明保留於 [README.zh-TW.md](../../README.zh-TW.md)；原 [README.en.md](../../README.en.md) 保留英文入口。詳細使用指南仍為繁體中文。
- 修正切換語系時混合顯示的匯入、登入及更新失敗訊息，並保留長篇未知診斷的完整內容。
- 統一資源檔換行格式，避免不同 checkout 環境造成多行提示比對失敗或殘留中文；原始診斷的換行保持原樣。

本版保留 `1.0.15` 的浮窗排版及操作回饋，以及 `1.0.14` 的背景更新效能調整：各卡片到期後個別更新，已完成卡片先顯示，服務內排隊不占用其他服務的查詢名額。

操作見[使用說明](../../使用說明.md#英文與繁體中文)，前版內容見 [1.0.15 版本說明](1.0.15.md)。

## 升級與回退

本機 preferences 格式升為 `8`，匯出設定格式升為 `7`，加入語系。舊本機設定仍可載入；缺少語系時使用英文。帳號、有效連接與 provider 原始用量格式維持原有契約，切換語系不發出新的用量查詢。

只支援本機格式 `7` 的舊 App 無法讀取新版偏好設定，會使用預設值並阻擋覆寫新版格式；不要刪除原設定檔。新版匯出檔也不能直接匯入只支援格式 `6` 的舊 App。需要回退時，保留升級前的備份或繼續使用新版；換回舊 EXE 不等於設定可直接降版。細節見[相容性原則](../COMPATIBILITY_POLICY.md)及[設定格式](../TECHNICAL_OVERVIEW.md#主題與配色)。
