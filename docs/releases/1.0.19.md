# AI Usage Dashboard 1.0.19

`1.0.19 / sequence 1033` 已沿用同一組凍結候選正式公開。[v1.0.19 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.19) 為 stable／latest；下載資訊見 [README](../../README.md#current-release)。App 為 `1.0.19`，Updater 沿用已簽署的 `1.0.18` 原始 bytes。

## 本版內容

- Claude Code `2.1.285` 的 `/usage` 回應若在 `usage` 欄位包含 `fallback_credit: null`，不再只因這個已觀察到的欄位被判為格式不相容。
- `fallback_credit` 的其他值與其餘未知欄位仍依原有安全檢查拒絕；沒有額度數字的回應不會被當作有效額度。
- Claude Code 最低版本仍為 `2.1.169`，缺少新欄位的舊回應格式繼續支援。

## 升級

本次只調整 Claude `/usage` 回應解析，未改動帳號、設定或用量檔案格式，也未更動 CLI 來源、簽章、帳號隔離與查詢安全要求。既有卡片不會只因 App 更新而要求重新連接。

## 建置與驗證

候選建立前，曾以已登入且通過簽章檢查的 Claude Code `2.1.285`，依 App 的參數受控執行一次 `/usage`。回應宣告 model turn、token 與 cost 均為零，`usage.fallback_credit` 為 `null`；可見文字只有訂閱提示，沒有額度百分比。這次觀察並非本版 App 成品的真人額度顯示驗收，也未重新驗證登入流程。
