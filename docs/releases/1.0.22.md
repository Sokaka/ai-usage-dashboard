# AI Usage Dashboard 1.0.22

`1.0.22` 為準備中的發布候選，尚未公開。本文件會在同一組候選完成凍結及公開驗證後回填成品與驗收紀錄。

## 本版內容

- 修正 Antigravity CLI 回傳新增 Gemini 4 Argon 群組後，整張 AGY 卡片顯示讀取失敗的問題。
- 保留舊版兩群組格式；新增的 `gemini-argon-wtu-weekly` 必須通過欄位、週期、數值、重置時間與兩份回應的一致性檢查。未知群組、重複或矛盾資料仍會拒絕。
- 卡片目前仍顯示原有 Gemini 與 Claude 的週用量及 5 小時用量，不顯示 Argon 獨立週額度。
- App 與 Updater 的內附 .NET runtime 更新至 `8.0.32`，SDK 固定為 `8.0.426`，修補前版 `8.0.31` 的已知安全問題。`System.Text.Json` 等既有 `10.0.12` 套件維持原版。

## 升級

本次修正不變更帳號、偏好、用量快取或 provider 綁定格式。既有格式錯誤會依原本的自動重試流程恢復，不需清除設定；其他來源、簽章、帳號隔離及零用量安全要求維持。

本版 App 與 Updater 均重新建置為 `1.0.22`；不沿用含舊 runtime 的 Updater。更新後依既有授權接受機制確認變動的元件條款，不清除 provider 登入資料。`.NET 8` 的支援期限仍為 `2026-11-10`，本次 patch 不延長上游支援。

## 建置與驗證

新增 43 個合成回歸案例，涵蓋兩組及三組資料、群組與區間排序、選用欄位、非法或未知資料、兩份回應不一致、安全計數與升級後既有格式錯誤標記的恢復。

候選前的修正版 production DLL 在 CLI `1.4.5` 完成一次受控用量查詢，回傳四個原有用量項目，程序成功且 conversation／turn／所有 token 零值檢查通過；未保存原始用量輸出。這是 source probe，不是本版正式成品驗收。

同 source Windows CI、候選 workflow、六件凍結成品及正式下載驗證待完成。完整的真人登入、背景刷新、乾淨 Windows 初裝、既有安裝一鍵更新與 UI／無障礙尚未以本版成品驗證。逐平台狀態見 [1.0.22 CLI 實測表](../CLI_COMPATIBILITY.md#1022)。
