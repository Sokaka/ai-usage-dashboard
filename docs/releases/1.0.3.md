# AI Usage Dashboard 1.0.3

目前為私有候選，Repository 維持 private，Release 維持 draft／prerelease，尚無正式公開下載。候選 workflow、獨立成品回讀、有界靜態隱私檢查與既有 Windows 主機離線換版均已完成；暫緩及未驗證界線列於下方。

## 本版內容

- Copilot 訂閱讀取支援 CLI `1.x` 的新舊回應：回應可包含 token、將 token 省略，或將該欄位設為 null；App 不會讀取回應中的 token。
- Copilot 通過帳號與方案核對後會顯示訂閱方案，並依 `token_based_billing` 顯示 `AI Credits` 或 `Premium requests`；計費模式缺少時顯示 `Premium usage`，訂閱讀取失敗時保留已驗證 quota 並提示問題。
- Copilot 繼續使用本機官方 CLI，要求正式版 `>=1.0.79` 且 `<2.0.0`；App 的 `GitHub.Copilot.SDK` 固定為 `1.0.11`，既有帳號、憑證與用量快取格式不變。
- 保留「關於 AI Usage」、開始選單捷徑、四種主題、五種服務卡片、精簡語系資源，以及支援與安全回報入口。
