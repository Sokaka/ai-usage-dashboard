# AI Usage Dashboard 1.0.15

`1.0.15 / sequence 1029` 已沿用同一組凍結候選正式公開。[v1.0.15 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.15) 為 stable／latest；下載資訊見 [README](../../README.md#目前版本)，前版紀錄見 [1.0.14 版本說明](1.0.14.md)。

## 本版內容

- 改善收合浮窗展開時的尺寸與排版流程，減少重複排版，保留工作區、DPI 與停靠位置的校正。
- Claude 帳號編輯畫面明確說明「儲存並連接」即接受用量風險，「儲存」可留待稍後決定。
- 統一設定匯入前後的重新連接提示，涵蓋五個 provider、Codex workspace ID，以及現有 Copilot 與 Grok 登入資料的清理說明。
- 重新連接既有 Codex workspace 卡片時，優先引導 workspace 連接，並明示改為一般帳號連接會解除原本的 workspace 限定。
- 卡片狀態提示提供資料時間；觀測時間不明時，另列本機讀取時間。
- Copilot 用量提示保留完整額度與額外使用狀態，卡面維持精簡數字。
- Antigravity 提交連接後關閉視窗時，提示等待提交完成；提交前仍提示取消與清理。
- 提高四種主題的捲軸對比。
- 改善單卡檢查的排隊與執行回饋；合併重複請求後，仍能更新開始檢查的提示。
- 排序規則視窗依工作區與 DPI 限制尺寸，內容過高時可捲動，並保留關閉按鈕。

操作見[使用說明](../../使用說明.md)，實作見[技術總覽](../TECHNICAL_OVERVIEW.md)。

## 沿用 1.0.14 的背景更新

背景每 10 秒檢查已啟用並連接的卡片是否到期，同時最多查詢四張卡片。已綁定的非 Antigravity 卡片各自完成更新並提早顯示，慢速卡片不會擋住其他卡片的下一輪。Claude、workspace-bound Codex 與 Grok 保留服務內排隊；排隊等待不占用其他服務的查詢名額，也不消耗實際查詢的期限。這些行為已在 `1.0.14` 發布，本版繼續沿用。
