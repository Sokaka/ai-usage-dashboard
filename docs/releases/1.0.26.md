# AI Usage Dashboard 1.0.26

`1.0.26 / sequence 1040`：已正式公開；公開時為 stable／latest，沿用同一組凍結成品。[v1.0.26 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.26)。

## 本版內容

- Claude 卡片已有用量資料時，除 Ultra 外都保留 5 小時用量列；來源未回傳這項用量時顯示「未提供／Not provided」，不補成 0%。
- Team、Max、Pro 或未知方案的來源已回傳 0% 時，仍顯示「已使用 0%／Used 0%」；沒有重置資訊時顯示「未提供重置時間／Reset time not provided」。
- Ultra 缺少 5 小時用量時不補列；已回傳 0% 且沒有重置時間或重置說明時仍隱藏，其他來源回傳的 5 小時用量保留。完全沒有用量資料時不補列。
- 週用量正常顯示；卡片摘要、用量列、Ready／Stale 與中英文切換採相同規則。提示只在顯示層產生，不寫入原始 snapshot 或快取，也不參與原始額度排序。

## 升級

帳號、偏好、既有連接、快取格式與 CLI 版本要求維持，不需清除設定或重新登入。沿用既有 Max 5x／Ultra 20x 辨識、原始訂閱分類、帳號／組織綁定及安全檢查，不增加 CLI 或 API 查詢。

App `1.0.26` 沿用前版 `1.0.25` 交付、最初由 `v1.0.23` 發布的 `1.0.23` Updater 原始 bytes，未重新建置、重簽或替換。第三方元件與授權 manifest 的本次核對結果：SDK、runtime、NuGet 版本、project 檔與第三方授權 manifest 對照前版 source 無差異；凍結成品實際離線匯出與 source manifest 核對通過。
