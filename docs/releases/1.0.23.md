# AI Usage Dashboard 1.0.23

`1.0.23 / sequence 1037` 已沿用同一組凍結候選正式公開。[v1.0.23 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.23) 為 stable／latest；App 與 Updater 均為 `1.0.23`。

## 本版內容

- Claude 的 5 小時用量為 0%，且沒有重置時間或重置說明時，卡片會隱藏該列；週用量仍顯示。
- 有非零用量、重置時間或重置說明時保留 5 小時列；其他 provider 的顯示不變。卡片摘要套用相同規則。
- App 與 Updater 的內附 .NET runtime 更新至 `8.0.33`，SDK 固定為 `8.0.427`，採用 [Microsoft 10/25 安全更新](https://github.com/dotnet/core/blob/main/release-notes/8.0/8.0.33/8.0.33.md)。既有 NuGet 套件版本維持不變。

這項 Claude 顯示規則不依方案名稱判斷，也不保證帳號沒有 5 小時限制；來源提供但無法解析的時間也可能是空值。

## 升級

帳號、偏好、用量快取與 provider 綁定格式維持；舊快取與 status line 備用來源也採用相同顯示規則。CLI 版本要求維持，不需清除設定或重新登入。

App 與 Updater 均重新建置為 `1.0.23`；不沿用含舊 runtime 的 Updater。元件版本與授權 digest 改變後，依既有流程重新確認條款；provider 登入資料保留。`.NET 8` 的支援期限仍為 `2026-11-10`，本次 patch 不延長上游支援。

## 建置與驗證

新增 16 個合成回歸案例，涵蓋新舊 metric key、有效與過期 snapshot、週額度保留、非零用量與重置資訊、缺少用量、其他 provider、備用摘要及解析器至卡片的投影。Updater 子程序 fixture 使用隔離的暫存目錄，並在 exit code 不符時提供 stderr；安全驗證條件維持。
