# AI Usage Dashboard 1.0.7

`1.0.7 / sequence 1021` 是目前的 immutable stable／latest 版本。[v1.0.7 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.7) 沿用原候選的六件凍結檔案，公開時沒有重建、重簽或替換。Source 為 [`c4ad25f41e973b508583252945aafa05572a4299`](https://github.com/Sokaka/ai-usage-dashboard/commit/c4ad25f41e973b508583252945aafa05572a4299)。

## 本版內容

- Production AGY 只直接呼叫使用者已安裝、核准的官方 `agy -p /usage --output-format stream-json`；正式 App 不再使用 ConPTY、`cmd.exe`、reviewed output 或 status-line capture。
- AGY 設定畫面改由 App process 內載入 `AiUsageDashboard.Antigravity.Setup.dll`；正式套件移除 standalone `AiUsageDashboard.Antigravity.Setup.exe` 與 `AiUsageDashboard.AntigravityCapture.exe`，只保留 App 與 ClaudeCapture 兩個 EXE。
- AGY version probe 與 `/usage` 都限制為單一 child process，並使用不含 `PATH`／`COMSPEC` 的縮減環境。App manifest 明確使用 `asInvoker`、`uiAccess=false`。
- 升級時只清理能以 ownership marker、路徑、內容、ACL 與並行狀態證明由 AI Usage 建立的舊 AGY status line/helper；自訂或無法驗證的設定保持不變。

一般使用不需要先執行 `/statusline off`。
