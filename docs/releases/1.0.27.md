## 本版內容

- 修正 Claude Code `2.1.318` 新增 `credential_expires_at` 登入到期資訊後，用量回應被拒絕、卡片持續保留舊資料的相容性問題。
- 接受可省略、帶時區的 ISO 8601 到期時間；過去日期、UTC、明確時區偏移與不同小數秒位數均有合成回歸案例。不以此欄判定帳號失效、額度或重置時間。
- 保留非零 token、turn、cost、權限遭拒、重複欄位及未知用量欄位的安全檢查。既有 Claude 回應仍可省略到期資訊，5 小時與週用量的顯示規則維持。

## 升級與驗證範圍

帳號、偏好、既有連接、快取格式與 CLI 版本要求維持；本次不需要清除設定或重新登入。已沿用前版 `1.0.26` 交付的 `1.0.23` Updater 原始 bytes，未重新建置、重簽或替換；候選與正式下載驗簽均核對沿用結果。
