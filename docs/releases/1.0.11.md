# AI Usage Dashboard 1.0.11

`1.0.11 / sequence 1025` 已正式公開。從 [v1.0.11 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.11) 下載；一般安裝與帳號設定見[使用說明](../../使用說明.md)。

## 本版內容

- 修正 Claude Free 帳號的提示與 Grok CLI 版號辨識。
- 統一 App 視窗、提示及四種主題下的視窗與系統匣圖示。
- 自動排序先依服務，再依 5 小時及週用量的重置時間排列；排序選項旁可查看規則說明。
- 收合浮窗圖示可自由拖曳，位置會限制在畫面矩形範圍內。
- 從浮窗開啟的重置券、排序規則及「關於 AI Usage」視窗會隨浮窗收合或隱藏，恢復浮窗時再次顯示。
- 本版沿用前一正式版已簽署的 `1.0.8` Updater 原始 bytes，維護 Updater 版本仍為 `1.0.8`。

## 尚未完成的驗收

本版尚未以五個平台的實際官方 CLI 完成真人登入與用量查詢，也未逐版實測舊版與最新版 CLI。從既有 `1.0.10` 標準安裝執行 App 按鈕的 signed online update、乾淨 Windows 初裝、舊版 Updater 自我交接及完整 UI／無障礙驗收亦未以本版完成；先前版本的真人或安裝結果及本版合成回歸測試都不代替本版實測。逐平台狀態見 [1.0.11 CLI 相容性表](../CLI_COMPATIBILITY.md#1011)。

服務串接依賴各平台官方 CLI 或 SDK；上游變更可能影響讀取。自有 EXE 尚無 Authenticode 簽章，Windows reputation 或端點政策可能提示或阻擋；請保留安全防護。已公開的成品不可替換，修正 bytes 須使用新版本與遞增 sequence。
