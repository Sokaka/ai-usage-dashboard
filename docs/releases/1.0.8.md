## 本版內容

- Codex 卡片在官方提供完整可用券明細時，顯示最近一張可用重置券的到期時間；距到期 48 小時內以警示色顯示。舊版只回傳次數或明細不完整時，仍顯示可用次數，不推測到期時間。
- Codex 卡片選單新增 **查看重置券**。視窗顯示官方回傳的可用總數、帳號、資料時間，以及可用券的名稱和到期資訊；不列出已使用、已到期或狀態未知的券。明細不完整或與總數矛盾時會提示，不補造資料。
- 視窗開啟時跟隨卡片快照更新；主浮窗收合或隱藏時一同隱藏，重新展開或顯示時恢復。逐券明細只保存在記憶體，不寫入用量快取或匯出設定。

## 尚未完成的驗收

Codex 舊版 count-only 回應、逐券狀態與到期時間，以及 Claude 新舊格式已有合成資料回歸測試；這不等於以實際官方 CLI 驗證舊版與最新版。`1.0.8` 正式成品尚未完成五個平台的真人登入與用量查詢、本機安裝、signed online update、舊版 Updater 自我交接或完整 UI／無障礙驗收。逐平台狀態見 [CLI 相容性表](../CLI_COMPATIBILITY.md#108-正式版)。

服務串接依賴各平台官方 CLI 或 SDK；上游變更可能影響讀取。自有 EXE 尚無 Authenticode 簽章，Windows reputation 或端點政策可能提示或阻擋；請保留安全防護。已公開的版本不可替換成品，修正須使用新版本與遞增 sequence。
