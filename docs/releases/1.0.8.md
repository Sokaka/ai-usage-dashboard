# AI Usage Dashboard 1.0.8（待候選建置）

`1.0.8` 尚未建立凍結候選；目前正式下載版仍是 [1.0.7](1.0.7.md)。本頁先記錄預計發布的功能與驗證欄位，候選建置、驗收及公開後須按實際結果回填。

## 本版內容

- Codex 卡片在官方提供完整可用券明細時，顯示最近一張可用重置券的到期時間；距到期 48 小時內以警示色顯示。舊版只回傳次數或明細不完整時，仍顯示可用次數，不推測到期時間。
- Codex 卡片選單新增 **查看重置券**。視窗顯示官方回傳的可用總數、帳號、資料時間，以及可用券的名稱和到期資訊；不列出已使用、已到期或狀態未知的券。明細不完整或與總數矛盾時會提示，不補造資料。
- 視窗開啟時跟隨卡片快照更新；主浮窗收合或隱藏時一同隱藏，重新展開或顯示時恢復。逐券明細只保存在記憶體，不寫入用量快取或匯出設定。
