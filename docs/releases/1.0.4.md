# AI Usage Dashboard 1.0.4

`1.0.4 / sequence 1018` 是歷史 stable 版本。[v1.0.4 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.4) 沿用原候選的六件凍結檔案，公開時沒有重建、重簽或替換。Source 為 [`4fa5b3c578c2e9a8bd22f53ff72a8ef8b91d200b`](https://github.com/Sokaka/ai-usage-dashboard/commit/4fa5b3c578c2e9a8bd22f53ff72a8ef8b91d200b)；目前 latest 版本見 [1.0.6 版本說明](1.0.6.md)。

## 本版內容

- App 啟動後會先說明更新檢查，約 30 秒後檢查已簽署的 stable feed；檢查本身不預先下載安裝檔，也可從系統匣手動檢查或關閉自動檢查。
- 有新版時，展開浮窗會顯示更新列，收合浮窗顯示 `↑` 提示。標準安裝版在維護 Updater 與安全關閉通道可用時，提供 **更新並重新啟動**；Updater 會再次驗證 feed 與檔案。
- 自訂安裝位置與免安裝 ZIP 提供下載入口，由使用者手動處理。修正維護 Updater 被鎖定時的自我更新交接，以及安全關閉 listener 意外停止後的狀態處理。詳細操作見[使用說明](../../使用說明.md#更新換機與移除)。

尚未完成乾淨 Windows 初裝、由 App 內提示發起的一鍵更新、由舊版 Updater 自行下載並交接新版的正式實測、custom／portable 操作、完整 UI／無障礙，以及五個 provider 的真人登入與用量驗收。本次使用 `1.0.4` 獨立 Updater 執行 `update-online`；維護 Updater 已更新為 `1.0.4`，但不代表 App 內一鍵流程或舊 Updater 自我交接已驗證。先前隔離環境的 `1.0.6-verify` → `1.0.7-verify` canonical managed 更新 E2E 通過 17 項 assertion，但使用不同的合成候選與成品，不能視為本版實機驗收。詳細界線見[實作與驗證清單](../../IMPLEMENTATION_CHECKLIST.md#104-歷史正式版)及 [CLI 相容性表](../CLI_COMPATIBILITY.md#104-正式版)。
