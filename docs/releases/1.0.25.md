# AI Usage Dashboard 1.0.25

`1.0.25 / sequence 1039` 已沿用同一組凍結候選正式公開。[v1.0.25 GitHub Release](https://github.com/Sokaka/ai-usage-dashboard/releases/tag/v1.0.25) 為 stable／latest；App 為 `1.0.25`，Updater 沿用 `1.0.23`。

## 本版內容

- 修正 Claude `/usage` 合法回應只有週用量時，卡片被判定為版本不相容的問題；仍須有全模型週用量，格式或安全檢查失敗時繼續拒絕。
- Ultra 沒有回傳 5 小時用量時隱藏該列；其他或未知方案顯示「未提供／Not provided」，不補成 0%。週用量正常顯示。
- 已有 5 小時用量的顯示規則維持；卡片摘要、用量列與中英文切換採相同規則。缺值提示只供顯示，不寫入原始 snapshot 或快取，也不參與額度排序。
- 沿用既有 Max 5x／Ultra 20x 辨識、原始訂閱分類、帳號／組織綁定與安全檢查；不增加 CLI 或 API 查詢。

## 升級

帳號、偏好與既有連接保留，快取格式與 CLI 版本要求維持，不需清除設定或重新登入。缺少 5 小時用量的快取重載後仍依方案顯示；提示不會被保存成實際額度。

App 沿用前版交付的 `1.0.23` Updater 原始 bytes，沒有重新建置或重簽；第三方元件與授權 manifest 不變。

## 建置與驗證

新增 43 個合成回歸案例，涵蓋只有週用量、缺少 5 小時用量、Ultra／其他／未知方案、語系切換、Ready／Stale、快取重載、原始 snapshot 保留，以及其他 provider 不受影響；錯誤格式與安全檢查維持拒絕。
