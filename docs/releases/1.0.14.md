## 本版內容

- 每 10 秒檢查已啟用並連接的卡片是否到期，再安排刷新。已綁定的非 Antigravity 卡片各自完成更新，慢速卡片不會擋住其他卡片的下一輪；需要依序查詢帳號的服務仍保留排隊。

本版尚未完成五個平台官方 CLI 的真人登入與用量查詢、基準及最新正式 CLI 的逐版實測。逐平台狀態見 [1.0.14 CLI 實測表](../CLI_COMPATIBILITY.md#1014)；歷史版本與合成測試的結果不代替本版實測。
