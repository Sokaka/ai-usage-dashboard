# AI Usage Dashboard 1.0.14

`1.0.14` 是背景用量更新修正版候選，尚未正式公開。目前正式版本仍為 `1.0.13`，下載資訊見 [README](../../README.md#目前版本)。

## 本版內容

- 背景定期檢查已啟用並連接的卡片是否到期，再安排刷新。已綁定的非 Antigravity 卡片各自完成更新，慢速卡片不會擋住其他卡片的下一輪；需要依序查詢帳號的服務仍保留排隊。
- 同時最多查詢四張卡片。Claude、workspace-bound Codex 與 Grok 在各自服務內先排隊，再取得查詢名額；排隊等待不消耗實際查詢的期限。
- 停用、移除或切換帳號後，晚到的舊結果會核對卡片狀態與查詢順序。資料到達重置或過期時間時，仍會更新顯示，並沿用原有身分與用量安全檢查。

操作見[使用說明](../../使用說明.md#更新與暫停檢查)，實作見[技術總覽](../TECHNICAL_OVERVIEW.md)。

## 驗證範圍

本文件保存候選 source 提交時的範圍。同 source Windows CI、候選 workflow、成品凍結及資產核對結果，另於同一候選 Release 的驗證紀錄登錄。

本版尚未完成五個平台官方 CLI 的真人登入與用量查詢、基準及最新正式 CLI 的逐版實測。逐平台狀態見 [1.0.14 CLI 實測表](../CLI_COMPATIBILITY.md#1014)；歷史版本與合成測試的結果不代替本版實測。

乾淨 Windows 初次安裝、條款視窗接受與拒絕、既有標準安裝從 `1.0.13` 的 App 一鍵線上更新、舊 Updater 交接，以及完整 UI／無障礙驗收仍待完成。正式端點的匿名下載與驗簽須於公開後另行核對。

服務串接依賴官方 CLI 或 SDK，上游變更可能影響讀取。自有 EXE 尚無 Authenticode 簽章，請保留 Windows 安全防護；其他限制見[使用限制](../../README.md#使用限制)及[公開決策](../../RELEASING.md#最後公開決策)。
