# AI Usage Dashboard 1.0.2

此版為歷史私有候選，未曾正式公開；最新正式版本與目前驗證範圍見 [1.0.5 版本說明](1.0.5.md)。以下保留 `1.0.2` 當時已完成的檢查與未驗證範圍。

## 本版變更

- 浮窗與系統匣新增「關於 AI Usage」，可查看／複製完整版本、開啟使用說明、Releases 與問題回報入口。
- 標準安裝建立 **AI Usage** 開始選單捷徑，升級可補建；遇到既有不相符的捷徑會保留並提示。自訂安裝位置與免安裝 ZIP 不建立捷徑。
- Copilot 使用本機官方 CLI，主包不再隨附第三方 CLI。需要正式版 `>=1.0.79` 且 `<2.0.0`，App 的 `GitHub.Copilot.SDK` 固定為 `1.0.11`。CLI 缺少或不符時保留卡片與憑證，安裝或修正後可重試。
- 安裝包只保留繁中、簡中、英文與日文的執行環境語系資源；App 介面仍為繁中。
- 四個一般主題的捲動條底色與用量 bar 底色一致，降低 hover／drag 的顏色反差。
- 補齊支援、安全回報、Issue 表單與合成畫面預覽，方便第一次使用及回報問題。
