## 本版內容

- 修正新版 Grok CLI 使用 `X Corp.` 簽章者後，被誤判為需要安裝或更新的問題。同時接受 `X Corp.` 與原有 `X.AI LLC` 的精確 CN，仍要求有效 Authenticode 簽章，並保留官方來源、路徑、ACL、檔案鎖定及帳號綁定檢查。
- 保留既有帳號、設定、連接、快取及 CLI 版本要求；本次不需要清除設定或重新登入。
- 合成回歸涵蓋新舊簽章者、CN 大小寫與引號格式，以及相似名稱、組織欄位假冒、缺少 CN、複合 CN 與無效簽章的拒絕；這些案例不代表新舊 Grok CLI 均已完成真人登入或用量查詢驗收。
